# 个人 Skill 存放区

将自己的 Skill 按文件夹放在这里，每个文件夹至少包含 `SKILL.md`，也可以包含 `scripts/`、`references/` 和 `assets/`。

```text
JustMe/
  my-skill/
    SKILL.md
    scripts/
```

除本说明外，这里的所有文件都已被 Git 忽略，不会自动进入公开仓库。不要强制提交原始文件。

新增或修改 Skill 后，在项目目录运行 `pnpm run vault:pack`，按提示输入私人区密码；密码不会显示或保存。该命令会更新 `public/vaults/` 下的加密包，再按正常发布流程提交加密包即可。单个 Skill 会提供包含全部文件的 `.zip` 下载，解压后即可使用。

私人入口保存在本机 `JustMe/PRIVATE-ENTRY.txt`，其中的随机密钥与密码共同用于解密，请收藏完整链接。链接和 `JustMe/.vault-local.json` 不会提交到 Git。备份这两个文件；在新电脑更新同一个私人区时需要原密钥。

此目录当前没有实际 Skill。空目录和不包含 `SKILL.md` 的 Skill 文件夹会在打包时明确报错，不会悄悄遗漏。`.git`、`node_modules`、`.DS_Store` 和本地环境文件不应作为 Skill 资源发布。符号链接不允许打包，避免意外带出目录外文件。

私人区采用 AES-256-GCM 加密，密码经 PBKDF2-SHA-256 派生密钥，同时使用私人链接中的随机密钥。密码不会写入网页源码；Skill 名称、说明和压缩包都在密文内部。解锁仅在浏览器内进行，刷新或点击“锁定”后需要重新输入密码，不保存到浏览器存储。

隐藏入口不等于账号权限。公开托管仍允许别人取得密文；如果完整私人链接泄露，较短密码可能被离线猜解。应使用较长的独立密码并保管私人链接。已下载的文件和历史密文无法被远程撤回；敏感凭据不应放在 Skill 中。
